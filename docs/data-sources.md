# 데이터 소스 전략

분양 정보 뉴스레터를 **합법적·안정적·저비용**으로 운영하기 위한 데이터 소스 정리.
결론부터: 호갱노노 크롤링 대신 **공공 OpenAPI + 언론 RSS** 조합을 쓴다.

## 1. 호갱노노 — 사용하지 않음 (왜)

- 이용약관상 크롤링(crawling)·스크래핑(scraping)·캐싱(caching)이 **명시적으로 금지**.
- 실제로 JSON 엔드포인트 접근 시 차단(bad request)됨 — 기술적으로도 불안정.
- 무단 수집은 약관 위반 + 데이터베이스권/부정경쟁 리스크. IPO 준비 기업엔 부적합.
- 합법적 사용 경로는 **B2B 데이터 제휴 문의**뿐. (직방 계열)

→ 호갱노노가 보여주는 정보(분양 일정, 세대수, 실거래가, 시황)는 아래 공식 소스 조합으로 대체 가능하다.

## 2. 코어 백본 — 청약홈 분양정보 OpenAPI

- 제공처: 한국부동산원, 공공데이터포털(data.go.kr)에서 활용신청 → 무료.
- 포맷: REST / JSON·XML, Swagger 명세 제공.
- 커버리지: APT(민간사전청약·신혼희망타운 포함), 오피스텔·도시형·생활숙박, 무순위/잔여세대,
  공공지원 민간임대, 임의공급 등 **분양 일정·세대수·청약 정보**.
- 활용: 뉴스레터의 단지 카드(시기·세대수·청약 일정)를 자동 동기화하는 1차 소스.
- 절차: data.go.kr 회원가입 → 활용신청 → 서비스키 발급 → 일/월 호출 한도 내 호출. *(키·한도 확인 필요)*

## 3. 시세·실거래가 — 국토부 실거래가 공개시스템 OpenAPI

- 아파트/오피스텔 매매·전월세 실거래가. 호갱노노 시세 기능의 합법 대체재.
- 단지별 주변 시세를 분양가와 비교해 "이 단지가 싸다/비싸다" 인사이트 제공 가능.

## 4. 건설사별 공급계획 — 수기 큐레이션

- 공식 API가 없는 영역. **비즈워치(B!z watch) 인포그래픽 + 각사 IR/보도자료**를 분기 단위로 갱신.
- 현재 시드 데이터(`assets/js/data.js`)가 정확히 이 소스(비즈워치 2026 공급계획)에서 정리됨.
- 운영 팁: 분기 초(1·4·7·10월)에 각사 발표를 받아 `SUPPLY_DATA`만 교체.

## 5. 핫이슈/뉴스 — RSS / 뉴스 API

- 크롤링 대신 **RSS 피드**가 합법·안정적.
  - 연합뉴스 부동산, 한국경제·매일경제 부동산, 비즈워치 등 섹션 RSS.
- 키워드 검색이 필요하면 **네이버 뉴스 검색 API**(검색 결과 메타·링크 제공).
- 표시광고 규제 관점: 헤드라인 인용 시 출처·링크 명시, 효능·시세 단정 표현 지양.

## 6. 운영 아키텍처 제안 (정식화 시)

```
[배치/크론]
  ├─ 청약홈 OpenAPI      → 분양 일정·세대수   ┐
  ├─ 실거래가 OpenAPI    → 주변 시세          ├→ 정규화 → projects.json → 정적 페이지 빌드
  ├─ 언론 RSS 수집       → 핫이슈 피드        ┘
  └─ 비즈워치/IR 수기 갱신 → 건설사 공급계획
```

- 1단계(현재): 정적 페이지 + 수기 `data.js`.
- 2단계: 위 OpenAPI를 호출하는 수집 스크립트(서버리스/크론) → JSON 산출 → 페이지가 fetch.
- 3단계: 단지별 집뷰 콘텐츠/제안 상태를 연동(세일즈 파이프라인).
